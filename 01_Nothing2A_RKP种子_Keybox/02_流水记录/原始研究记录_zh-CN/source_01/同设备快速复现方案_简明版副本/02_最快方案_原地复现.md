# 最快方案：原地复现

## 核心思想

不改 system/vendor，不替换系统 KeyMint TA，不擦 persist。

只保证：

```text
root 可用
patched TEE 可用
modified TA 能 direct 加载
stock KeyMint HAL/TA 仍然正常
```

## 为什么这样最快

Keybox 和 RKP 的复现不需要全量刷机。

Keybox 需要：

```text
direct 加载 patched KeyMint TA
读取 persist secure object
把明文 copy out
```

RKP 需要：

```text
direct 路线泄漏 RKP private scalar
stock Binder 路线生成 CSR
Google 返回证书链
```

所以最稳结构是：

```text
modified TA 只用于 direct 实验
stock TA/HAL 继续用于系统路径
```

## 一台已经准备好的设备

如果这台设备已经：

- 解锁
- root
- patched TEE
- 能运行 direct client

那以后复现不需要重新刷。

只要：

```text
插线
检查状态
跑 Keybox
跑 RKP
验证
归档
```

## 同型号新设备

同型号新设备先不要刷。

先做预检：

```text
型号对不对
系统版本对不对
KeyMint TA hash 对不对
HAL hash 对不对
root/TEE 条件能不能满足
persist 是否还在
```

预检通过，再跑快速复现。

预检不通过，再决定是适配当前版本，还是做指定版本准备包。

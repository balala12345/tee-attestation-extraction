# 先看我

一句话结论：

```text
不要想着做一个所有同型号都能乱刷的万能固件包。
最稳最快的是：不降级、不刷全量系统，在当前设备上做“原地快速复现”。
```

## 最推荐路线

```text
一次性准备设备：
  解锁 bootloader
  有 root
  patched TEE 能加载 modified Trustonic TA
  stock system/vendor/persist 保持不动

以后复现：
  插线
  跑一键脚本
  自动导出 Keybox 和 RKP 结果
```

## 为什么不建议万能固件包

因为同型号不等于同固件。真实限制来自：

- 系统版本
- 区域包
- bootloader / vbmeta / rollback index
- TEE / LK / preloader 版本
- KeyMint TA / HAL hash
- persist 是否保留

如果新设备版本比你的固件包高，强行刷低版本最危险。

## 最终目标

做一个类似这样的复现包：

```text
same_device_fast_repro/
  check_device/
  keybox/
  rkp/
  docs/
  runs/<设备序列号>/
```

最终操作者只需要懂：

```text
1. 先检查能不能跑。
2. 能跑就一键复现。
3. 不要随便降级刷机。
```

# 设备预检表

这个表用于判断“这台设备能不能直接快速复现”。

## 必须通过

| 检查项 | 通过条件 |
| --- | --- |
| 设备型号 | Nothing Phone (2a) / Pacman / MT6886 |
| bootloader | 已解锁 |
| root | `su` 可用 |
| TEE 服务 | `tee-1-1` running |
| KeyMint 服务 | `vendor.keymint-trustonic` running |
| Keystore | `keystore2` running |
| persist | 没有被擦，`attest_keybox.so` 还在 |
| 网络 | RKP 时能访问 Google remote provisioning endpoint |

## 最好一致

| 检查项 | 项目当前成功值 |
| --- | --- |
| stock KeyMint TA hash | `ad17a40a49cc0c812f78359a72d5d5c73b54eabac261f861db6d1f72b3b745b2` |
| stock KeyMint HAL hash | `bc3de2a984f9fdc418abdc3333f1cf75bde95d322037fe4c9375d52c2015810a` |
| Keybox patched TA hash | `92d66968007e462f1c56c7aaee4ca4d5deb4da8822ba396035001d72f67b1016` |
| RKP sideleak TA hash | `88f641c3cce8f98ed963481511853d60a9eb50b34344904cde27cba5632ce229` |

## 判断结果

### A. 直接复现

条件：

```text
型号一致
TA/HAL hash 一致
root/TEE 条件满足
```

动作：

```text
直接跑快速复现脚本
```

### B. 当前版本适配

条件：

```text
型号一致
但 TA 或 HAL hash 不一致
```

动作：

```text
不要降级
先拉当前版本 TA/HAL
重新适配 patch
再跑快速复现
```

### C. 不建议继续

条件：

```text
型号不一致
区域不清楚
版本高于准备包且想降级
persist 不完整
root/TEE 条件无法满足
```

动作：

```text
暂停，不刷机
先做备份和版本确认
```
